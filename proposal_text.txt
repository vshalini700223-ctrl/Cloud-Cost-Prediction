ABSTRACT
Cloud computing platforms such as Amazon Web Services (AWS), Microsoft
Azure, and Google Cloud provide computing resources through a pay-as-you-
go pricing model where users are charged based on the amount of resources
consumed. Estimating the cost of deploying applications in the cloud before
actual deployment is difficult because pricing depends on multiple resource
usage parameters such as CPU usage, memory allocation, storage capacity,
network bandwidth, and number of virtual machines. Due to the dynamic
nature of workloads and resource consumption, manual cost estimation
methods often produce inaccurate results, which may lead to inefficient
budgeting and resource planning.
This project proposes a Cloud Cost Prediction System that estimates cloud
cost using classical machine learning regression models. The system analyzes
historical cloud resource usage data and learns patterns that relate resource
utilization features to cloud cost. Three regression models are implemented in
this project: Linear Regression, Decision Tree Regression, and Random
Forest Regression. These models are trained to identify relationships between
resource usage variables and the corresponding cloud service cost.
Feature engineering techniques including feature extraction, feature selection,
and feature reduction are applied to identify the most relevant attributes
affecting cloud cost prediction. The models are evaluated using regression
performance metrics such as Mean Squared Error (MSE), Root Mean
Squared Error (RMSE), and R² score in order to determine the most accurate
prediction model. The proposed system aims to provide an approximate cloud
cost estimation based on resource utilization patterns and assist developers and
organizations in making better decisions when planning cloud infrastructure
deployments.

Introduction
Cloud computing enables organizations to access computing resources such as
servers, storage systems, and networking infrastructure through internet-
based platforms. Instead of maintaining physical infrastructure, users can
deploy applications on cloud platforms and pay only for the resources they
consume. This model allows organizations to scale resources dynamically
according to workload demands while reducing the need for large upfront
investments in hardware and maintenance.
Modern cloud platforms provide various services including Infrastructure as
a Service (IaaS), Platform as a Service (PaaS), and Software as a Service
(SaaS). Among these, infrastructure services such as virtual machines, storage
volumes, and networking services are widely used for hosting applications and
managing large-scale workloads. Because these resources are billed based on
consumption, understanding how resource utilization affects cost becomes an
important aspect of cloud infrastructure planning. However, predicting the cost
of cloud infrastructure before deployment remains challenging because cloud
pricing depends on several resource utilization parameters. Developers must
estimate how many virtual machines are required, how much storage will be
allocated, and how much network bandwidth will be consumed. Small changes
in these parameters can significantly influence the total cost of running
applications in the cloud.
Machine learning techniques can analyze historical cloud usage data to identify
patterns between resource utilization and cost. By training regression models
on such data, it becomes possible to estimate the expected cost of future cloud
configurations. This allows developers and organizations to make more
informed decisions about resource allocation and infrastructure planning. This
project focuses on developing a machine learning system that predicts cloud
cost based on resource usage attributes.

Problem Background
Cloud service providers charge users according to the consumption of
computing resources such as virtual machines, storage capacity, and network
traffic. When deploying applications in the cloud, developers must estimate the
required resources in advance in order to control operational costs. This
estimation process becomes critical when applications need to scale
dynamically or support large user workloads. However, estimating cloud cost
manually becomes difficult because multiple resource utilization factors
contribute to pricing. Increasing the number of virtual machines, allocating
larger storage volumes, or transferring larger amounts of network data can
significantly increase the final cloud bill. In addition, different application
workloads may require different combinations of computing resources, making
cost estimation even more complex.
Another challenge arises from the fact that cloud workloads often change over
time. For example, an application may require additional compute resources
during peak usage periods and fewer resources during low activity periods.
These variations make it difficult to accurately estimate the expected cost using
simple manual calculations or static pricing models. Because resource
utilization varies depending on workload patterns, manual cost estimation may
not always produce reliable predictions. As a result, organizations may
experience unexpected cloud expenses or inefficient resource planning. Poor
cost estimation may also lead to over-provisioning of resources, which wastes
budget, or under-provisioning, which affects application performance.
According to the widely cited study “A View of Cloud Computing”, cloud
pricing is directly influenced by the consumption of computing, storage, and
networking resources, which makes accurate cost estimation challenging for
cloud users.

Research Gap
Existing cloud management tools mainly provide cost monitoring and reporting
after cloud resources have already been deployed. These tools help analyze
billing information but provide limited support for estimating cloud costs
before deployment. As a result, developers often rely on manual estimation
methods or cloud provider pricing calculators when planning infrastructure.
Several research studies have explored machine learning approaches for
predicting cloud resource usage and workload performance. These studies
mainly focus on workload scheduling, resource allocation optimization, or
performance prediction in cloud environments. While these approaches
contribute to improving cloud infrastructure management, they do not always
focus directly on estimating the monetary cost associated with resource
utilization.
Additionally, many proposed prediction systems rely on complex deep learning
models or require large-scale datasets and high computational resources. Such
solutions may not be practical for smaller projects or environments where
computational resources and training datasets are limited.
Therefore, there is a need for a practical and interpretable machine learning
approach that can estimate cloud cost based on measurable resource utilization
parameters such as CPU usage, memory usage, storage size, network
bandwidth, and number of virtual machines.
This project focuses on developing a simplified cost prediction model using
classical machine learning techniques that can estimate cloud cost based on
historical usage data.
Research literature highlights that predicting cloud resource behavior and
associated costs is an active area of study in cloud computing systems.

usage and the corresponding cloud cost.
The dataset structure is inspired by publicly available cloud workload datasets
such as the Google Cluster Usage Dataset and similar datasets available on

 Memory usage (GB)

 Number of virtual machines
 Disk I/O operations
 Network I/O operations
 Instance type
 Workload duration
 Cloud cost (target variable)
Each row in the dataset represents a cloud workload configuration and its
corresponding cost. Example dataset record:
CPU Memory Storage Bandwidth VMs Cost
12 16GB 200GB 45GB 3 $58
8 8GB 120GB 20GB 2 $32
Cloud cost acts as the target variable, while the resource utilization attributes
are used as input features for training machine learning models.

Model
Three regression models are implemented in the proposed system.
Linear Regression
Linear Regression models the relationship between cloud resource usage
features and predicted cost using a linear mathematical equation. It provides a
baseline model for cost prediction.
Decision Tree Regression
Decision Tree Regression divides the dataset into multiple branches based on
feature values. Each branch represents a decision rule that predicts cloud cost
based on resource configuration.
Random Forest Regression
Random Forest Regression is an ensemble learning technique that combines
multiple decision trees. The final prediction is obtained by averaging
predictions from multiple trees. This reduces overfitting and improves
prediction stability.
Random Forest is particularly suitable for this project because cloud cost
relationships may involve nonlinear interactions between resource usage
parameters.

Mathematical Discription
Let the input feature vector be represented as:
X = (x1,x2,x3,x4,x5)
Where:
x₁ = CPU usage
x₂ = Memory usage
x₃ = Storage size
x₄ = Network bandwidth
x₅ = Number of virtual machines
These variables represent the primary cloud resource utilization parameters that
influence cloud pricing.
The predicted cloud cost is represented as:
Y = f(X)
where y represents the estimated cloud cost generated by the prediction model
based on the input feature vector.
For Linear Regression, the cost prediction function can be expressed as:
Y = β0+β1x1+β2x2+β3x3+β4x4+β5x5
where:
β₀ = intercept of the regression model
β₁…β₅ = coefficients representing the contribution of each resource utilization
feature to the predicted cost.
The regression model learns these coefficients during the training phase by
minimizing the prediction error between the actual cost values and the
predicted values. This mathematical formulation allows the system to model
the relationship between cloud resource utilization and the expected cost.

Experimental Data Complexity
Let:
n = number of samples in the dataset
m = number of features used for model training
The computational complexity of training the machine learning models used in
this project can be estimated as follows:
Linear Regression
O(nm2)
Linear Regression involves matrix operations for computing regression
coefficients. The complexity depends on the number of features and training
samples.
Decision Tree Regression
O(nlogn)
Decision Tree algorithms recursively partition the dataset based on feature
values to minimize prediction error.
Random Forest Regression
O(k . nlogn)
where: k = number of trees in the forest.
Random Forest builds multiple decision trees and combines their predictions.
Although it increases computational cost compared to a single decision tree, it
improves prediction stability and accuracy.

Result Verification
The performance of the proposed cloud cost prediction system will be verified
using standard regression evaluation metrics.
Mean Squared Error (MSE) measures the average squared difference
between predicted cost values and actual cost values. Lower MSE values
indicate better prediction accuracy.
Root Mean Squared Error (RMSE) represents the square root of MSE and
provides an interpretable measure of prediction error in the same units as the
target variable.
R² Score (Coefficient of Determination) measures how well the regression
model explains the variation in cloud cost based on the input features.
A higher R² score indicates that the model captures the relationship between
resource utilization and cloud cost more effectively.
These evaluation metrics allow quantitative assessment of the prediction
performance of each machine learning model.

Comparison
The three regression models used in this project - Linear Regression, Decision
Tree Regression, and Random Forest Regression - will be compared based on
their prediction performance.
Linear Regression serves as a baseline model and provides a simple
mathematical relationship between resource usage and cost. However, it may
not capture complex nonlinear interactions between features.
Decision Tree Regression can model nonlinear relationships by splitting the
dataset into multiple decision rules based on feature values. This allows it to
capture more complex patterns in the data.
Random Forest Regression combines multiple decision trees to produce a more
robust prediction. By averaging predictions from several trees, it reduces
overfitting and generally improves prediction accuracy.
The models will be compared using evaluation metrics such as MSE, RMSE,
and R² score. The model with the lowest prediction error and highest
explanatory power will be selected as the final model for cloud cost prediction.
In the final project implementation, graphical comparisons such as bar charts
or error plots may be used to visually compare the performance of different
models.
